# AGENTS

## Workflow
- Before starting any task, read `HISTORY.md` from the repository root.
- If a task modifies files, append a dated entry to `HISTORY.md` before finishing.
- For all Cloudflare deployment actions, follow [cloudflare-upload.md](cloudflare-upload.md) for token requirements and deployment commands.

## Required history format
- Use this format for each entry:
  - `## YYYY-MM-DD`
  - `- [done] <short description>`
  - `- files: <comma-separated file paths>`
  - `- status: <in_progress | completed>`
